# 🏦 Sistema Bancário em Python

Sistema bancário desenvolvido em Python como projeto de estudo, com o objetivo de praticar lógica de programação e manipulação de arquivos JSON.

## Funcionalidades

- Cadastro de clientes com nome e CPF.
- Login com CPF e senha.
- Criação de múltiplas contas.
- Consulta de saldo.
- Depósitos e saques.
- Transferências entre contas.
- Histórico de movimentações.
- Armazenamento de dados em JSON.

## Tecnologias utilizadas

- Python
- JSON
- Hashlib
- Datetime

## Como executar

1. Clone o repositório:
   `(https://github.com/VinnyzScript/sistema-bancario-python/tree/main)`

2. Entre na pasta:
   `cd sistema-bancario-python`

3. Execute o programa:
   `python banco.py`

## Objetivo

Projeto desenvolvido para aprimorar conhecimentos em Python e desenvolvimento de sistemas.

## Observação

Este projeto possui finalidade educacional e não deve ser utilizado para operações financeiras reais.
